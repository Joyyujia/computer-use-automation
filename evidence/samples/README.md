# Reviewed sample evidence

This directory contains redacted evidence generated by `npm run evidence:samples` against the fictional local application.

These runs are deliberately classified as `scripted_non_live_evidence`. They demonstrate the evidence format and the complete mechanics of discovery, artifact validation, deterministic replay for a second member, the `member_not_found` business outcome, and same-session handoff. They do **not** satisfy the assignment's required genuine API-backed discovery run.

`index.json` points to the reviewed runs from the included generation. Each invocation replaces the prior generated sample set while preserving this README, and normalizes absolute workspace paths before the fixtures are reviewed and committed.
