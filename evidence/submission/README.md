# Submission evidence

This directory contains the reviewed evidence submitted for the end-to-end automation flow. It contains only successful, relevant runs that were individually reviewed for secrets and sensitive data; unreviewed material under `evidence/runs/` remains ignored.

## Canonical evidence bundle

1. `live-discovery/`
   - Records genuine API-backed model discovery.
   - Its manifest, events, observations, result, and validation run identify the model-backed execution and retain provider response IDs.

2. `artifact/`
   - Contains the exact, unedited artifact generated by the live discovery run.
   - Its provenance records `createdFromLiveRun: true` and the discovery run ID.

3. `replay-second-member/`
   - Records deterministic replay of that artifact for a different valid member with model access disabled.

4. `replay-not-found/`
   - Records deterministic replay for an unknown member with result `business_outcome` and code `member_not_found`.

5. `replay-delayed/`
   - Records successful bounded waiting against the delayed-response fixture.

6. `same-session-handoff/`
   - Records replay pausing for session expiry, transferring the retained session to a human, recording the sanitized human action, returning control, and resuming successfully.

## Supplemental independent verification

`independent-verification/` records a fresh post-hardening API-backed discovery and a model-disabled replay of its exact generated artifact for a second valid member. It supplements rather than replaces the canonical evidence indexed by `index.json`, which also covers not-found, delayed-response, and same-session handoff paths.

## Path portability

Some raw manifests and results preserve their original `/Users/joywang/Desktop/...` runtime paths as execution provenance. Those absolute paths are not AI working files and are not expected to resolve on another machine. The repository-relative paths in `index.json` and `independent-verification/index.json` are the portable maps for reviewing the submitted evidence.

## Completed review checklist

- [x] `index.json` contains the actual run IDs, commands, statuses, and relative paths.
- [x] The second-member, not-found, delayed, and handoff runs use the exact artifact in `artifact/`.
- [x] The bundle was checked for API keys, credentials, raw sensitive input values, balances, email addresses, and unexpected URL query values.
- [x] The bundle excludes `.env`, browser storage, cookies, unreviewed screenshots, and failed exploratory runs.
- [x] `evidence/samples/` remains explicitly labeled as scripted evidence and is not presented as the API-backed submission run.
