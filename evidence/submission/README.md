# Submission evidence

This directory contains the reviewed evidence submitted for the end-to-end automation flow. Do not copy all of `evidence/runs/` here. Include only successful, relevant runs after reviewing every file for secrets and sensitive data.

## Required evidence

1. `live-discovery/`
   - Genuine API-backed model discovery.
   - Include `manifest.json`, `events.jsonl`, and `result.json`.
   - The evidence must contain provider response IDs and identify the run as model-backed.

2. `artifact/`
   - The exact artifact generated by the live discovery run.
   - Do not manually edit the artifact between discovery and replay.
   - Its provenance must include `createdFromLiveRun: true`.

3. `replay-second-member/`
   - Deterministic replay of the exact generated artifact for a different valid member.
   - Run with model access disabled.
   - Include `manifest.json`, `events.jsonl`, and `result.json`.

4. `replay-not-found/`
   - Deterministic replay for an unknown member.
   - The result must be `business_outcome` with code `member_not_found`.

5. `replay-delayed/`
   - Deterministic replay against the delayed-response fixture.
   - The result must show successful bounded waiting.

6. `same-session-handoff/`
   - Replay that pauses for session expiry, transfers the retained session to a human, records the sanitized human actions, returns control, and resumes successfully.

## Supplemental independent verification

`independent-verification/` records a fresh post-hardening API-backed discovery and a model-disabled replay of its exact generated artifact for a second valid member. It supplements rather than replaces the canonical evidence indexed by `index.json`, which also covers not-found, delayed-response, and same-session handoff paths.

## Before committing

- Complete `index.json` with the actual run IDs, commands, statuses, and relative paths.
- Confirm the second-member, not-found, delayed, and handoff runs use the exact artifact in `artifact/`.
- Search for API keys, credentials, raw sensitive input values, balances, email addresses, and unexpected URL query values.
- Do not include `.env`, browser storage, cookies, unreviewed screenshots, or failed exploratory runs.
- Keep `evidence/samples/` labeled as scripted evidence; it is not a substitute for this directory.
